## 5. 競合ギャップ分析「何が負けているか」(実スクレイプ 2026-06-01)

モデル A = my-favorite-giants(歴史網羅型) / モデル B = baseballdata.jp(セイバー・条件別集計型)。

確定した現状(実取得):

- **打者(有データ)= split 充実◯**(打順/vs球団/本拠ビジター/イニング3分割/曜日/月/交流戦)。
- **投手 = 通算+直近登板の2表のみ、split 全部×**。
- 打者投手 共通で × : vs左右 / 球場別 / RISP / グラフ / プロフィール / 年度別履歴。

- トピクラ片方向(記事→選手データの逆リンク無し、横リンク無し、SNSシェア無し)。

負けている要点(優先度順):

1. 投手 split が丸ごと無い(打者はあるのに) — 最大の非対称な穴
2. vs左右 / 球場別 / RISP が打者投手とも無い(Pillar)
3. ランキング面・読み物面・順位面が 404(回遊先が3面)
4. プロフィール・年度別履歴が無い(A に負け)
5. トピクラが片方向(設計①③未実装)
6. SABR(OPS止まり)/ pitch-level / 選球眼 / 得点差別 / 殊勲打(B に深さで負け)
7. UX(検索/フィルタ/ソート/今日の注目 無し)

## 7.5 ★SEO 可視性 gap(実測 2026-06-01)— 最大の負けは機能でなく index

データサイトの真の負け = 「検索で見つけられない」。

| 観点 | A MFG | B BBD | C yoshilover/data |
|---|---|---|---|
| indexed 規模感 | ~1,200 URL | 数万URL級(1選手7-8ページ) | /data ~150 URL、`site:yoshilover.com/data`=**0件**・自クエリ圏外 |
| 構造化データ JSON-LD | Dataset | **無し** | **SportsPlayer+PropertyValue=最厚** |
| title/meta 検索意図 | 可 | desc定型で弱 | **最良**(選手名先頭+成績+固有desc) |

- **訂正(当初の楽観を破棄)**: 「技術SEOが上だから勝てる」は**誤り**。検索順位は コンテンツの深さ・網羅・トピック権威・被リンク・滞在 で決まり、meta/JSON-LD は hygiene であって順位の決定打ではない。コンテンツ大敗(面3/列7/当季のみ §7.6)なら、同じクエリでは index されても順位で勝てない。`site:`0件は「未クロール」より薄さ+権威不足の症状。
- **正しい因果**: SEO はコンテンツと権威の結果であり独立レバーでない。コンテンツ大敗=SEOも負け。技術SEOが整っているのは出場資格であって勝因ではない。
- **純データサイトとしては A にも B にも勝てない**。唯一の勝ち筋 = データ対決を降りる: A=記事ゼロ/鮮度ゼロ、B=巨人編集/文脈/速報ゼロ。両者が持たない「**巨人特化 × 即日速報 × データを記事文脈に埋める媒体性**」だけが残された土俵。長期戦で保証なし。
- **含意**: 456-461 も index されねば見られないが、index/権威は コンテンツ深化+媒体性+内部リンク+継続 の結果でしか付かず、**SEO 単体の近道は無い**。

## 7.7 データ記事エンジンの実態 + 実装順序(parity → 差別化)

/data ページとは別に `【巨人データ】`記事の量産エンジンが既に実装済(`insight_nightly.py` + publisher3本 + detector + dedup349 + quality gate356)。LIVE角度: z-score異常値/守備/連続記録/順位変動/各種ランキング/counting/本拠ビジター/vs球団/vs左右/イニング/RISP/カウント/チーム系。
**阻害4点**: ①角度の約半分が空固定で未生成 ②title が機械f-stringで発見表現不可 ③`ENABLE_DATA_INSIGHT_AUTO_DRAFT`(default0)依存=prod ON要verify ④サヨナラ/逆転/殊勲打は派生可能だが検知コードゼロ。

**実装順序(user 方針)**: まず parity(ライバルにあるもの)→ それに差別化4点。

Phase 1 parity(実現可能): 投手split(456)/ pillar vs左右RISP(457)/ SABR whitelist内(461)/ カウント別球場別pillar配線(457拡張)/ チーム順位表+集計+未来試合(459)/ ランキング面(462)/ 殊勲打得点差別detector(463)/ サヨナラHR DB(463)/ 現役fill改善(460)。
parity不可(土俵を降りる): pitch-level・選球眼(別source)/ 歴史網羅・通算・年度別(backfill source無)/ プロフィール(source無)。

Phase 2 差別化: A眠り角度の再活性化(464)/ B新角度サヨナラ逆転殊勲打通算◯本目(463)/ C title発見ドリブン化(465)/ D 新鮮さ最適化+エンジンON verify(466)。

実装チケット: 456-461(データサイト)+ 462-466(データ記事)= GH #120-130。
