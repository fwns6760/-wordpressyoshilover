## 我々の現状(2026-06-02 時点・事実)

- **今季データ**: 選手別 通算 / 直近5試合 / 打順別 / vs球団 / 本拠ビジター / イニング / 曜日 / 月 / 交流戦 / 得点圏(RISP) / 対左右 / セイバー16指標(456 / 457 / 461)。
- **鮮度**: 毎日更新。セ順位表・今後の試合・予告先発(NPB scrape、459)。
- **履歴の素材**: 467 で **全選手の NPB career(年度別+通算+プロフィール+ドラフト)を毎日 scrape 済** → 歴史系の素材が一部手元にある。
- **ランキング**: `/data/ranking` = 今季の選手ランキング(打撃/投手 8カテゴリ)。
- **選手検索**: `/data/` cluster に選手名インクリメンタル検索(460)。
- **持っていないもの**: 過去の「試合単位」データ(insight.db は今季 box 中心)。

## 戦略(455 と整合)

- 🟢🟡(scrape できる集計 / 履歴)は積極的に潰す。
- 🔴(過去の試合単位 backfill が必要なもの)は **土俵を降りる**(投資対効果が悪い)。

## 構築バックログ(上から順に潰す)

### 🟢 Tier 1 — 今すぐ作れる(素材が手元 / NPB scrape 確立済)

- [x] **468-1 通算成績ランキング(打撃/投手)**
    - ライバル: `通算打撃成績` / `通算投手成績`(選手間ランキング)
    - 実装: 467 で取得済の全選手 career 通算を**横断集計** → `/data/ranking` に「通算」タブを追加。
    - 効果: 相手の主力ページに正面から並ぶ。**最安・最速**。素材=既存。

- [ ] **468-2 ドラフト指名選手一覧**
    - ライバル: `ドラフト指名` / `育成ドラフト` / `ドラフト外` / `指名競合`
    - 実装: 467 profile の `ドラフト` 情報 + NPB 公式ドラフトページ scrape(URL 要確認)。
    - 効果: オフ需要 + 歴史厚み。

- [ ] **468-3 NPB 年度別順位表(歴代)**
    - ライバル: `NPB年度別順位表(1936-)`
    - 実装: `npb.jp` 歴代 standings を scrape(現行 `fetch_npb_cl_standings` の歴代版)。
    - 効果: 「順位の歴史」を 1 ページで。

- [ ] **468-4 選手名鑑プロフィールの露出強化**
    - ライバル: `選手検索一覧` / `球団プロフィール`
    - 実装: 467 で取得済(生年月日 / 身長体重 / 投打 / 経歴 / ドラフト)を選手一覧・検索結果にも露出。
    - 効果: 「名鑑」感の補強。素材=既存。

### 🟡 Tier 2 — 中コスト(scrape 設計が要る)

- [ ] **468-5 監督別通算成績** — ライバル `監督別通算成績`。歴代監督の勝敗・年度。
- [ ] **468-6 タイトル・表彰受賞歴** — MVP / 沢村賞 / ベストナイン / 新人王 等。NPB title 系 scrape。
- [ ] **468-7 歴代○代目(4番打者 / 主将 / 開幕投手)** — 半静的、年 1 更新級。
- [ ] **468-8 通算記録マイルストーン** — 通算本塁打 / 安打の節目到達(467 career から導出可)。

### 🔴 Tier 3 — 非推奨(過去の試合単位 backfill が必要、土俵を降りる)

- 球場別 / 対戦相手別 勝敗(全年)、年度別 守備 / 代打 / 盗塁阻止、CS / 日本シリーズ全史、全試合出場一覧、東京ドーム年度別勝敗 等。
- 理由: 我々は**過去の試合単位データを保持していない**。これらは大規模 backfill が前提で、コスト>効果。455 で「歴史網羅は追わない」と判断済。

## 右サイドバー全クロール → 抜け漏れ再点検(2026-06-03 追加)

ライバル右サイドバーを全列挙したところ、当初 Tier 分けで**取りこぼしていた「安い高価値」群**が判明。
ライバルの「データNo.1」の正体は過去の試合単位 archive ではなく、**記録室 / タイトル / 名球会・殿堂 / マイルストーン**という
**半静的 or career データ(467)から導出可能**なブロック。ここは「捨てる archive」ではなく**積極的に奪う**対象。

### 🟢 Tier 1+ — 追加の即作れる群(career 467 から導出 / 半静的)

- [ ] **468-9 記録室ハブ「巨人 個人最高記録」** — ライバル `個人最高記録(通算/シーズン/連続試合)` `チーム最高記録` `三冠王` `完全試合・無安打無得点` `サイクルヒット`。
    - 実装: 467 career 横断集計(通算 TOP)+ 半静的リスト(三冠王/完全試合/サイクル=年1更新級の固定表)。1 ハブページに束ねる。
    - 効果: ライバルの「記録室」ブロックに正面で並ぶ。**素材は概ね手元 or 固定表**。
- [ ] **468-10 名球会カウントダウン + 会員リスト** — ライバル `名球会会員リスト` + マイルストーン。

    - 効果: ファン価値最大級・低コスト(468-8 を昇格・具体化)。
- [ ] **468-11 野球殿堂(巨人関連)** — ライバル `野球殿堂リスト`。半静的リスト、年1更新。

- [ ] **468-13 球団変遷 / 本拠地比較** — 完全静的、1 ページで即。
